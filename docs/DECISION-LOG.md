# Decision log

A dated, one-line-per-decision index of what this project decided. It is a
pointer, not a second source of truth: each row's **Ref** names the file and
section where the reasoning lives. The reasoning lives in:

- **`README.md`**: its sections explain the app's rules and why they hold.
- **Commit messages**: each carries the why for its change. A Ref of
  `git history (sha)` means the commit message is the only place it is written.
- **`docs/DECISIONS.md`**: for reasoning with no other home, mostly process
  and tooling.

Repo-only: never built or shipped. `docs/CASE-STUDY.md` turns these facts into
a story.

## How to keep this file

- **Add a file, not a row.** A new decision goes in `docs/decision-log/` as its
  own file named `YYYY-MM-DD-short-name.md` (lowercase, hyphenated), holding
  exactly one table row. Never edit the table on a branch: rows appended to the
  same last line by parallel branches always conflict, and separate files never
  do.
- **Fold on the default branch.** `npm run decision-log -- --fold` appends the
  waiting entries to the end of the table in filename order (date, then name)
  and deletes their files. Run it on the default branch, in a commit of its
  own, whenever the folder gets long. `npm run decision-log` without the flag
  validates the entries and prints them, and `npm test` fails on a malformed
  one.
- **One row per decision, not per commit.** A reversed decision gets a new row
  of kind Reversed. The old row stays.
- **Say the decision, not the change** ("Transit stopped counting against the
  seven", not "edit types.ts").
- **Kind** is one of the list below, kept in code as `KINDS` in
  `scripts/decision-log-lib.mjs`:
  - **Product**: what the app does and the rules it holds to.
  - **Design**: how it looks and feels: layout, colour, icon, interaction.
  - **Content**: the words on screen.
  - **Engineering**: how it is built, stored, tested and deployed.
  - **Process**: how the project itself is run.
  - **Declined**: a deliberate no, kept on the record so it is not re-litigated.
  - **Reversed**: an earlier row undone. Name what it reverses.
- **Ref** names the file → section holding the why. If no why is written
  anywhere, write it there first (in `docs/DECISIONS.md` if nowhere else fits).
